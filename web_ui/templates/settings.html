Connect your AI

This app doesn't come with its own AI. Instead, it connects to an AI you already pay for, using an API key — a secret code that lets this app talk to that AI on your behalf. Adding an API key is a completely normal, standard thing to do: it's the official way to use these AIs directly, and it works out much cheaper than paying a middleman for a subscription. You only do it once. Pick whichever suits you:

# Upper bounds on everything, and they matter more here than in most projects.
#
# This app is installed by people who cannot debug it. A dependency that
# releases a breaking change does not produce a bug report from them -- it
# produces somebody who installed the thing, saw a stack trace, and decided the
# app is broken. There is no `pip install --upgrade` in their life and no
# reason there should be.
#
# So every line is bounded at the next major above the version this was last
# tested against, and the versions tested are written beside them. That is not
# theoretical: `openai` was pinned at >=1.50 and the installed version here is
# 3.1 -- two majors past what anybody checked, and working only by luck.
#
# Raising one of these is a small job: bump it, run the suite, update the
# comment. Leaving them open is a large one, done by a stranger, badly.
